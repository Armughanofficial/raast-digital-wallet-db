# Raast Integrated Digital Wallet & Monitoring System 🏦

## 📌 Project Overview
A real-world Fintech database system designed for **CS2013** at FAST-NUCES. It simulates Pakistan’s **Raast payment infrastructure**, managing digital wallets, P2P transfers, and automated fraud monitoring.

## 🛠️ Implementation Details
* **DBMS:** MySQL (Workbench / XAMPP)
* **ACID Transactions:** Implemented for secure transfers between wallets.
* **Automated Triggers:** Detects high-value transactions (> Rs. 100k) and failed attempts.
* **Optimized Views:** Custom reporting for transaction summaries and fraud alerts.
